# Clean Food Filter: cleaned product photos

Product photos used by the Clean Food Filter app, served with GitHub Pages.

Each image is an edit of a product photo from [Open Food Facts](https://world.openfoodfacts.org): the background was
replaced with white by an open-source cutout model (U²-Net). Nothing on the package was redrawn or generated.

- **Licence:** the original photos are by Open Food Facts contributors under
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/); these edited versions are shared under the same
  licence. Each file is named after the product's barcode; the original is on that product's Open Food Facts page,
  `https://world.openfoodfacts.org/product/<barcode>`.
- **Layout:** `p/<first 3 digits of the barcode>/<barcode>.webp`, 400 px square, white background.
